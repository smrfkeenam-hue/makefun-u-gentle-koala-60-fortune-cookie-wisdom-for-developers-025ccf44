# Agent notes

Entry for make.fun's "Fortune Cookie Wisdom for Developers" bounty: one original fortune-cookie line for a software developer, 81 characters — "You will ship on Friday, and the bug you fear most will introduce itself by name." It uses the classic fortune-cookie "You will..." rhythm, a truth every developer recognises (the dreaded Friday deploy and the bug you have been avoiding), and a quiet twist on the second read (the bug knows your name — it was yours all along). Built in this session: the kit's RULES.txt and competition.yaml were read first, the line was drafted against the judge's criteria (fortune-cookie form, developer truth, fresh turn, double meaning), and main.py was written with the write/edit tools in three separate messages (initial write, output-path helper, main() function with __main__ guard) with the output verified byte-identical after each revision.
